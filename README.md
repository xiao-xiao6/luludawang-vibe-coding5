# 推币机 · Coin Pusher

一个纯前端、零依赖、可直接打开就玩的推币机小游戏。俯视视角的电玩城机台：
投币 → 推板往复 → 币堆互撞 → 掉出前沿拿钱 → 升级机台 → 换台重生。

**打开方式**：双击 `index.html` 即可（不需要服务器、不需要构建、不联网）。

---

## 玩法

| 操作 | 说明 |
| --- | --- |
| 点击台面任意位置 | 在该横向位置投币（落点有瞄准提示） |
| `空格` | 在当前位置投币 |
| `A` | 开关自动投币机（需先购买） |
| `L` | 抽奖（需 5 张券） |
| `P` | 暂停 / 继续推板 |
| `Esc` | 关闭面板 |

- **推板**在台面上方往复运动，把币堆往出币口推。
- 币越过最前方的**出币口**（青色高亮线）→ 按面值结算收益。
- 币掉进左右两角的**黑色斜纹沟** → 直接丢币，不给钱。
- 台面近似水平，**只有推板能推动币**，所以挂机不会白拿钱（已实测：90 秒纯挂机收益 0）。
- **金币见底**时机台会自动赠送救济金（30 金币），也可以直接点 HUD 上的「领救济金」立刻领取。
- **暂停推板**时推板停住，台面上的币仍然继续求解，不会卡住也不会穿模。

### 币种

| 币 | 面值 | 特殊 |
| --- | --- | --- |
| 铜币 | 1 | 基础 |
| 银币 | 3 | 较重，推起来更"实" |
| 金币 | 10 | 高价值 |
| 钻石币 | 25 | 掉落额外给 1 颗钻石（有日志与特效反馈） |
| 幸运币 | 2 | 掉落额外给 1 张抽奖券 |
| 宝箱 | — | 推落触发 **JACKPOT**：现金奖励 + 撒 41 枚币到场 |

### 连击

连击是**滑动窗口计数**：统计最近 **0.9 秒**内推落的枚数，而不是"只要间隔不超时就越滚越大"的单调计数器。

| 窗口内推落 | 倍率 |
| --- | --- |
| 6 枚 | ×1.4 |
| 11 枚 | ×1.8 |
| 18 枚 | ×2.5 |
| 30 枚 | ×4.0 |

倍率是**爆发奖励**而不是常驻增益：0.9 秒内推落 30 枚（约 33 枚/秒）才拿得到 ×4，
稳态推币只能吃到 ×1.4 ~ ×1.8。连击徽章只在**跨档**时弹出，震屏也跟着档位走，
所以高倍率在表现上是"稀有事件"，不会满屏乱抖。

### 升级

**金币升级**（8 项）：推板马达、行程连杆、滑板涂层、侧护栏、投币口、自动投币机、幸运石、扩容槽。

**钻石升级**（2 项）：

- **磁力线圈**：在物理求解器内部对前沿的币施加真实横向力，把快要掉沟的币往中心带。
- **暴击芯片**：每枚推落的币有 **10% / 级**概率触发暴击 ×2（满级 30%），期望收益 +10% / 级。

所有升级都映射到真实仿真参数（速度 / 行程 / 摩擦 / 沟宽 / 容量 / 投币数 / 补给权重 / 自动频率），
玩家能"感觉到"升级，而不只是看到数字变大。

### 换机台（Prestige）

累计收益达到门槛后可以**换机台**：清空全部升级与钻石升级，随机换一台带修饰的新机台，
并获得**永久收益加成**（每层 +20%）。

| 机台 | 修饰 |
| --- | --- |
| 标准机台 | 没有任何额外修正，最稳的一台 |
| 贪心机台 | 角沟宽 25%，但所有收益 +20% |
| 温柔机台 | 角沟收窄 25%，但所有收益 -10% |
| 富矿机台 | 机台补给好币更多（幸运 +2），推板慢 10% |
| 涡轮机台 | 推板快 18%，但台面摩擦略大 |

### 概率公开

「统计与玩法」面板里直接读代码里的同一张表，公示的概率和实现永远是同一个：

- **抽奖**（5 张券 / 次）：金币 +120~420 **32%** / 钻石 +1~3 **24%** / 金币雨 ×最多 10 **20%** /
  钻石雨 ×最多 5 **15%** / JACKPOT **9%**
- **连击判定**：0.9 秒窗口内推落 6/11/18/30 枚 → ×1.4/1.8/2.5/4.0
- **暴击芯片**：每级 +10% 概率触发 ×2
- **宝箱出现率**：每次补给按当前幸运等级实时计算（基础 1% + 幸运加成，上限 2.5%），冷却 28 秒

**台面满时的抽奖与 Jackpot 不会空放**：撒不下去的币会按面值折算成金币补偿给玩家，
日志里会写明"台面已满，折算 +N 金币"。抽到的奖励不会凭空蒸发。

## 项目结构

```
推币机项目/
├── index.html          入口（双击即玩）
├── style.css           霓虹电玩城主题
├── .gitignore          忽略测试/构建产物
├── js/
│   ├── physics.js      物理内核：币/推板/碰撞/结算（零 DOM，可 headless）
│   ├── data.js         数据层：币种/连击/升级/成就/奖池/机台修饰（纯数据）
│   ├── engine.js       逻辑层：经济/抽奖/存档/成就/换机台（零 DOM）
│   ├── fx.js           特效层：粒子/飘字/震屏/程序化音效
│   ├── layout.js       适配层：视口分级/台面尺寸/性能档位（零 DOM）
│   └── app.js          表现层：渲染/输入/面板/存档节奏
└── _test/
    ├── smoke_test.js   自检：物理/经济/存档/成就/换机台/音效状态/双端适配（202 项）
    └── tune.js         调参：扫描台面几何，实测掉币率
```

**分层原则**：`physics` / `data` / `engine` 完全不碰 DOM，可以在 Node 里跑完整局。
所以自检脚本能用 `node` 直接验证玩法逻辑，而不需要开浏览器。

## 自检

```bash
node _test/smoke_test.js   # 202 项检查
node _test/tune.js         # 台面几何调参表
```

自检覆盖：

- **物理稳定性**：3000 步无 NaN、币不陷进推板（硬约束）、币间重叠可控、不出界、容量上限生效
- **暂停推板**：推板停住、币仍正常求解、无穿透
- **挂机收益**：90 秒纯挂机收益必须 ≈ 0（防止"放着不管就赚钱"）
- **经济**：投币扣费、结算入账、角沟不给钱、连击阶梯、滑动窗口归零、投币口倍投
- **升级**：成本递增、等级封顶、满级不可购买、钻石升级独立生效、扩容槽同时抬高容量与补给线
- **抽奖 / Jackpot / 成就**：券不足拦截、结果多样性、满台不空放（折算补偿）、撒币数上报正确、长线成就存在
- **存档**：往返一致、残缺存档容错、**损坏存档字段级校验**（防 NaN 白嫖 / 防等级越界）、
  **扩容后读档不丢币**、Lv0 自动投币开关不被读档带回、reset 清档
- **破产保护**：金币见底能拿到救济金、Lv0 空开关不屏蔽救济金
- **换机台**：门槛拦截、清空升级、发放启动金币、随机修饰真的作用到物理参数
- **音效状态机**：挂起音频上下文不改变开关状态、点一次静音就真的静音
- **长时压力**：模拟 3 分钟连续游玩，检查 NaN / 容量 / 重叠 / 穿透
- **经济平衡实测**：固定种子下的稳态投入产出比（可复现）
- **双端适配**：视口分级正确、台面宽高比恒定、机柜与日志不溢出、安全区只扣一次、性能档位与 DPR 上限生效

### 平衡实测结果

固定随机种子，先预热 120 秒排空初始赠币，再测 90 秒稳态：

| 机台状态 | 投入 | 产出 | 比值 |
| --- | --- | --- | --- |
| 初始 | 208 ◎ | 197 ◎ | **0.95**（略亏，逼你升级） |
| 中期（部分升级） | 624 ◎ | 668 ◎ | **1.07** |
| 满配 | 1040 ◎ | 4064 ◎ | **3.91** |
| 满配 + 暴击 Lv3（同种子对照） | 1040 ◎ | 5174 ◎ | **4.97**（+27%） |

曲线是"起步略亏 → 升级后转正 → 满配效率高但仍有上限"，不会指数膨胀。
暴击芯片的边际收益是 **+27%**，和其它升级处在同一量级，不再是一枝独秀的断层最优解。

### 可复现性

所有随机都走**可播种 RNG**（`data.js` 的 `makeRng`，mulberry32），并且分成两条独立通道：

- `world.rng` —— 物理与掉落，决定仿真轨迹
- `rollRng` —— 暴击等结算随机

同一份种子跑两次，结果**完全一致**（自检里有这条断言）。所以平衡测试是真正的回归门禁，
而不是"每次跑都重新抽一次样"。两条流分开之后，暴击不会扰动物理轨迹，
"满配 vs 满配+暴击"的差异就只剩暴击本身，测出来的数字才干净。

## 双端适配

桌面端和手机端不是两套代码，而是**同一套判定**（`js/layout.js`，纯函数、零 DOM、可 headless 自检）：
按视口分出 4 档，再由 CSS 变量与 `body[data-mode]` 落地，避免「电脑正常、手机炸布局」。

| 档位 | 触发条件 | 布局 | 台面（典型） |
| --- | --- | --- | --- |
| `wide` | 宽度 ≥ 861 | 机柜 + 日志右列 | 1920×1080 → 496×599 |
| `stack` | 平板竖屏 / 中等宽度 | 单列，日志折到机柜下方 | 820×1180 → 576×696 |
| `narrow` | 宽度 ≤ 480 | 单列 + 操作区两行 + 大按钮 | 390×844 → 346×418 |
| `compact` | 横屏且高度 ≤ 560 | 台面在左、HUD 与操作在右 | 844×390 → 270×326 |

要点：

- **宽高比恒定**：台面永远 480:580，先按宽度铺满、再按可用高度回收，宁可变小也不变形。
- **安全区只扣一次**：`env(safe-area-inset-*)` 用隐藏探针实测，写进 `--safe-*` 变量，
  由 JS 从可用宽高里扣一次、CSS 负责把内容摆进安全区内。同一份刘海空间不会被算两遍，
  刘海屏上台面能拿到真实的可用空间。
- **触控**：`touch-action:none` 防止拖台面时页面跟着滚；`pointer:coarse` 下按钮一律 ≥44px、
  投币键 ≥52px；手机端提示语自动换成「点台面投币 · 拖动可瞄准」。
- **高清与性能**：DPR 上限统一由适配层决定（低端机压到 1.5、桌面 2），档位变化时自动重烘焙
  币精灵与静态台面；内存 ≤2G 或核心 ≤3 自动降粒子、桌面保留全特效。
- **手机横屏**：台面在左、HUD 与操作在右，纵向空间全给台面；横向放不下日志时自动收起日志列，
  超矮横屏再砍掉状态条保按钮。

## 调参记录（为什么是现在这组数值）

初版推板行程只有 34px，而币堆铺了 286px —— **推板只能蹭到最前排，后面的币一辈子推不动**，
表现就是"玩三分钟掉出 0 枚"。`_test/tune.js` 扫描了 8 组台面几何后选定：

| 配置 | 掉出/投入 | 场上币数 |
| --- | --- | --- |
| 行程 72px | 0.458 | 300 |
| 行程 102px | 0.737 | 266 |
| **行程 132px（当前）** | **0.866** | 230 |
| 行程 162px | 0.978 | 195 |

行程 132px 时掉币率足够高、场上币数也够满，兼顾了"爽"和"台面饱满"。
（这张表由可播种 RNG 生成，每次跑都一致。）

## 技术要点

- **物理**：自研固定步长冲量求解器（120Hz），币-币用均匀网格做粗筛，
  推板是**硬约束**（币永远不会陷进去），共 10 次迭代。磁力线圈与推板一样，
  在积分阶段施加真实力，不做事后坐标修正。
- **渲染**：币精灵与**整张静态台面**（网格 / 导轨 / 角沟 / 出币口 / PAYOUT 标签 /
  推板渐变 / 推板前沿辉光）全部预烘焙成离屏 canvas，主循环只做 `drawImage` ——
  不再每帧重建渐变、也不再每帧跑 `shadowBlur`。绘制顺序用的排序缓冲也会复用，
  不每帧分配新数组。
- **音效**：全部用 WebAudio **程序化合成**（振荡器 + 噪声 + 带通滤波），零音频文件。
  连击音高按对数阶梯上行（1→0, 2→2, 4→4, 8→6, 16→8, 32→10, 64+→11 个半音），
  高连击也能听出区别，不会一过阈值就永远是最高音。
  音效开关只有一个真源 `soundOn`，按钮状态、`aria-pressed`、静音判定全部读它；
  切走标签页只挂起音频上下文、不改开关，切回来音效还在。
- **存档**：`localStorage`，每 10 秒 + 页面隐藏 + 关闭时落盘。
  存档上限**跟随台面容量**（扩容槽升到多少就存多少，不会读档丢币）；
  `fromJSON` 对每个字段做类型与范围校验，非法值回落默认或夹紧。
- **无障碍**：弹窗有焦点陷阱与焦点还原、面板打开时屏蔽游戏快捷键、
  事件日志只增量追加新条目（读屏器不会反复播报整张列表）、
  `prefers-reduced-motion` 下关闭全部动画。
- **面板**：商店购买只更新受影响的那张卡片，滚动位置不跳、键盘焦点不丢。
