# 推币机 · Coin Pusher

一个纯前端、零依赖、可直接打开就玩的推币机小游戏。俯视视角的电玩城机台：
投币 → 推板往复 → 币堆互撞 → 掉出前沿拿钱 → 升级机台 → 继续推。

**打开方式**：双击 `index.html` 即可（不需要服务器、不需要构建、不联网）。

---

## 玩法

| 操作 | 说明 |
| --- | --- |
| 点击台面任意位置 | 在该横向位置投币（落点有瞄准线提示） |
| `空格` | 在当前位置投币 |
| `A` | 开关自动投币机 |
| `L` | 抽奖（需 5 张券） |
| `Esc` | 关闭面板 |

- **推板**在台面上方往复运动，把币堆往出币口推。
- 币越过最前方的**出币口**（青色高亮线）→ 按面值结算收益。
- 币掉进左右两角的**黑色斜纹沟** → 直接丢币，不给钱。
- 台面近似水平，**只有推板能推动币**，所以挂机不会白拿钱（已实测：90 秒纯挂机收益 0）。

### 币种

| 币 | 面值 | 特殊 |
| --- | --- | --- |
| 铜币 | 1 | 基础 |
| 银币 | 3 | 较重，推起来更"实" |
| 金币 | 10 | 高价值 |
| 钻石币 | 25 | 掉落额外给 1 颗钻石 |
| 幸运币 | 2 | 掉落额外给 1 张抽奖券 |
| 宝箱 | — | 推落触发 **JACKPOT**：现金奖励 + 撒 41 枚币到场 |

### 连击

窗口内连续推落会累积连击，倍率按阶梯跳：

| 连击 | 倍率 |
| --- | --- |
| 5 枚 | ×1.4 |
| 12 枚 | ×1.8 |
| 25 枚 | ×2.5 |
| 50 枚 | ×4.0 |

倍率是**爆发奖励**而不是常驻增益，所以高倍率很稀有 —— 这是为了不让初始机台变成印钞机（见下方平衡实测）。

### 升级

**金币升级**（8 项）：推板马达、行程连杆、滑板涂层、侧护栏、投币口、自动投币机、幸运石、扩容槽。

**钻石升级**（2 项）：磁力线圈（把前沿的币往中心吸，少掉沟）、暴击芯片（所有连击倍率 +0.5）。

## 项目结构

```
推币机项目/
├── index.html          入口（双击即玩）
├── style.css           霓虹电玩城主题
├── js/
│   ├── physics.js      物理内核：币/推板/碰撞/结算（零 DOM，可 headless）
│   ├── data.js         数据层：币种/连击/升级/成就（纯数据）
│   ├── engine.js       逻辑层：经济/抽奖/存档/成就（零 DOM）
│   ├── fx.js           特效层：粒子/飘字/震屏/程序化音效
│   ├── layout.js       适配层：视口分级/台面尺寸/性能档位（零 DOM）
│   └── app.js          表现层：渲染/输入/面板/存档节奏
└── _test/
    ├── smoke_test.js   自检：物理/经济/存档/成就/双端适配（425 项）
    └── tune.js         调参：扫描台面几何，实测掉币率
```

**分层原则**：`physics` / `data` / `engine` 完全不碰 DOM，可以在 Node 里跑完整局。
所以自检脚本能用 `node` 直接验证玩法逻辑，而不需要开浏览器。

## 自检

```bash
node _test/smoke_test.js   # 425 项检查
node _test/tune.js         # 台面几何调参表
```

自检覆盖：

- **物理稳定性**：3000 步无 NaN、币不陷进推板（硬约束）、币间重叠可控、不出界、容量上限生效
- **挂机收益**：90 秒纯挂机收益必须 ≈ 0（防止"放着不管就赚钱"）
- **经济**：投币扣费、结算入账、角沟不给钱、连击阶梯、投币口倍投
- **升级**：成本递增、等级封顶、满级不可购买、钻石升级独立生效
- **抽奖/Jackpot/成就**：券不足拦截、结果多样性、宝箱触发撒币、成就不崩溃
- **存档**：往返一致、残缺存档容错、reset 清档
- **长时压力**：模拟 3 分钟连续游玩，检查 NaN / 容量 / 重叠 / 穿透
- **经济平衡实测**：自动投币测稳态投入产出比
- **双端适配**：视口分级正确、台面宽高比恒定、机柜与日志不溢出、安全区压缩后仍可玩、性能档位与 DPR 上限生效

### 平衡实测结果

| 机台状态 | 投入 | 产出 | 比值 |
| --- | --- | --- | --- |
| 初始 | 208 ◎ | 187 ◎ | **0.90**（略亏，逼你升级） |
| 中期（部分升级） | 624 ◎ | 1859 ◎ | **2.98** |
| 满配 | 1040 ◎ | 4012 ◎ | **3.86** |

曲线是"起步略亏 → 升级后转正 → 满配效率高但仍有上限"，不会指数膨胀。

## 双端适配

桌面端和手机端不是两套代码，而是**同一套判定**（`js/layout.js`，纯函数、零 DOM、可 headless 自检）：
按视口分出 4 档，再由 CSS 变量与 `body[data-mode]` 落地，避免「电脑正常、手机炸布局」。

| 档位 | 触发条件 | 布局 | 台面（典型） |
| --- | --- | --- | --- |
| `wide` | 宽度 ≥ 861 | 机柜 + 日志右列 | 1920×1080 → 496×599 |
| `stack` | 平板竖屏 / 中等宽度 | 单列，日志折到机柜下方 | 820×1180 → 576×696 |
| `narrow` | 宽度 ≤ 480 | 单列 + 操作区两行 + 大按钮 | 390×844 → 346×418 |
| `compact` | 横屏且高度 ≤ 560 | 台面在左、HUD 与操作在右 | 844×390 → 270×326 |

实测方案表（DPR 按真机取值，由适配层算出）：

| 视口 | 档位 | 机柜 | 日志 | 台面 | DPR |
| --- | --- | --- | --- | --- | --- |
| 桌面 1920×1080 | wide | 520 | 右列 300 | 496×599 | 1 |
| 笔记本 1366×768 | wide | 520 | 右列 300 | 429×518 | 1 |
| 平板横屏 1024×768 | wide | 520 | 右列 300 | 429×518 | 2 |
| 平板竖屏 820×1180 | stack | 600 | 折到下方 | 576×696 | 2 |
| 手机竖屏 390×844 | narrow | 370 | 折到下方 | 346×418 | 2 |
| 小屏竖屏 360×640 | narrow | 340 | 折到下方 | 281×340 | 2 |
| 手机横屏 844×390 | compact | 470 | 右列 200 | 270×326 | 2 |
| 小屏横屏 667×375 | compact | 457 | 收起 | 257×311 | 2 |

要点：

- **宽高比恒定**：台面永远 480:580，先按宽度铺满、再按可用高度回收，宁可变小也不变形。
- **安全区**：`env(safe-area-inset-*)` 用隐藏探针实测后计入机柜纵向占用；刘海屏不挡按钮，
  底部指示条不压投币键，左右安全区过宽时还会把日志列收掉换台面宽度。
- **触控**：`touch-action:none` 防止拖台面时页面跟着滚；`pointer:coarse` 下按钮一律 ≥44px、
  投币键 ≥52px；手机端提示语自动换成「点台面投币 · 拖动可瞄准」。
- **高清与性能**：DPR 上限统一由适配层决定（低端机压到 1.5、桌面 2），档位变化时自动重烘焙币精灵；
  内存 ≤2G 或核心 ≤3 自动降粒子、桌面保留全特效。
- **手机横屏**：台面在左、HUD 与操作在右，纵向空间全给台面；横向放不下日志时自动收起日志列，
  超矮横屏再砍掉状态条保按钮。

## 调参记录（为什么是现在这组数值）

初版推板行程只有 34px，而币堆铺了 286px —— **推板只能蹭到最前排，后面的币一辈子推不动**，
表现就是"玩三分钟掉出 0 枚"。`_test/tune.js` 扫描了 8 组台面几何后选定：

| 配置 | 掉出/投入 | 场上币数 |
| --- | --- | --- |
| 行程 72px | 0.497 | 297 |
| 行程 102px | 0.715 | 266 |
| **行程 132px（当前）** | **0.872** | 230 |
| 行程 162px | 0.950 | 193 |

行程 132px 时掉币率足够高、场上币数也够满，兼顾了"爽"和"台面饱满"。

## 技术要点

- **物理**：自研固定步长冲量求解器（120Hz），币-币用均匀网格做粗筛，
  推板是**硬约束**（币永远不会陷进去），共 10 次迭代。
- **渲染**：币精灵预烘焙成离屏 canvas 缓存（按 dpr 放大），主循环只做 `drawImage`，
  避免每帧重画渐变；台面网格/斜纹/辉光按静态分层绘制。
- **音效**：全部用 WebAudio **程序化合成**（振荡器 + 噪声 + 带通滤波），
  零音频文件。连击音高按半音阶梯上行，越推越高。
- **存档**：`localStorage`，每 10 秒 + 页面隐藏 + 关闭时落盘。
- **无障碍**：弹窗有焦点陷阱与焦点还原、`aria-live` 播报、`prefers-reduced-motion`
  下关闭全部动画。
